# 🚗 Telegram-бот мониторинга очереди на границе

Умный бот для мониторинга ситуации на пограничных переходах (Брест, Берестовица, Брузги). Отличается высокой точностью расчёта времени ожидания благодаря накоплению и анализу исторических данных, а также продвинутой системой оповещений.

---

## 📋 Возможности

### 🌍 Мониторинг зон ожидания
*   **Брест** (Брест-ТС)
*   **Берестовица**
*   **Брузги**

### ⏱️ Гибкий интервал опроса
*   Быстрые пресеты: 3 мин, 10 мин.
*   Произвольный интервал от 1 до 1440 минут.

### 🚗 Фильтр по номеру машины
*   Отслеживание конкретной машины в очереди.
*   Отображение текущей позиции и статуса.
*   **Автоматическое напоминание** включить сирену сразу после установки фильтра.
*   Легкое отключение фильтра одной кнопкой.

### 🚨 "Живая" сирена при вызове в ПП
*   **Непрерывное оповещение:** бот отправляет по 3 сообщения каждую минуту, пока машина находится в статусе "Вызван в ПП".
*   **Мгновенная проверка:** при нажатии кнопки "🔔 Включить сирену" бот сразу проверяет текущий статус. Если машина *уже* вызвана, сирена срабатывает мгновенно, не дожидаясь следующего цикла опроса.
*   **Автоматическая остановка:** сирена сама выключается, как только машина меняет статус (например, проехала ПП) или когда пользователь снимает фильтр.

### 📊 Умный расчёт "Оценка для вас"
*   **Сбор истории:** фоновый процесс собирает статистику по всем зонам каждые 30 минут, независимо от активности пользователей.
*   **Усреднение:** расчёт строится на основе средних значений за выбранный период, что сглаживает аномалии API.
*   **Адаптивное отображение:**
    *   Менее 24 часов: `~X ч Y мин.`
    *   Более 24 часов: `~X сут. Y ч Z мин.`
*   **Прозрачность:** в отчёте отдельной строкой указывается, на основе скольких записей сделан расчёт.

### ⚙️ Админ-панель (только для владельца)
*   **📊 Период усреднения:** настройка горизонта расчёта (6, 12, 24, 48, 72 часа).
*   **👥 Пользователи:** просмотр списка, блокировка, разблокировка, полное удаление.
*   **💾 Бэкап базы:** скачивание файла `bot_users.db` прямо в Telegram для безопасного обновления кода без потери истории.

### 📈 Отслеживание активности
*   Фиксация времени последней активности и счётчика сообщений для каждого пользователя.
*   Визуальные статусы: 🟢 активен, 🟡 недавно, 🔴 давно.

### 🛡️ Надёжность и автовосстановление
*   **Защита от зависаний:** встроенный счётчик ошибок в цикле мониторинга. При 5 подряд неудачных запросах поток безопасно останавливается и отправляет пользователю уведомление с просьбой перезапустить мониторинг (`/start`).
*   Логирование "пульса" работы фоновых задач для удобной отладки.

## ⚙️ Локальная установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   cd OcheredGranicaAllPL
   ```

2. **Создание виртуального окружения:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Linux/macOS:
   source .venv/bin/activate
   ```

3. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка переменных окружения:**
   Создайте файл `.env` в корне проекта и добавьте:
   ```env
   API_TOKEN=ваш_токен_от_BotFather
   ADMIN_CHAT_ID=ваш_telegram_id
   ```
   *(ID можно узнать у бота [@userinfobot](https://t.me/userinfobot))*

5. **Запуск:**
   ```bash
   python botALLPL.py
   ```

## 🚀 Развертывание (Деплой)

Бот написан на стандартном Python и может быть развернут на **любом хостинге**, поддерживающем Python 3 (Render, Railway, Heroku, PythonAnywhere, VPS/VDS, Docker и др.).

### Общие шаги для любого хостинга:
1. **Загрузите код** на сервер (через Git или FTP).
2. **Установите зависимости:** `pip install -r requirements.txt`
3. **Настройте переменные окружения** (Environment Variables) в панели управления хостинга:
   * `API_TOKEN` = ваш токен
   * `ADMIN_CHAT_ID` = ваш Telegram ID
4. **Запустите бота:** `python botALLPL.py`

> 💡 **Рекомендация:** Для постоянной работы используйте менеджер процессов (например, `systemd` на VPS, `PM2` или встроенные механизмы перезапуска облачных платформ), чтобы бот автоматически поднимался после сбоев.

## 💾 Сохранение и восстановление базы данных (ВАЖНО)

База данных `bot_users.db` содержит историю статистики (для точных расчётов) и список пользователей. **Без неё расчёты времени ожидания будут неточными.**

### Процесс безопасного обновления бота:

1. **Сделайте бэкап:**
   * Отправьте боту `/admin` или нажмите **"⚙️ Админ-панель"**.
   * Нажмите **"💾 Бэкап базы"**.
   * Скачайте файл `bot_users.db` из Telegram и сохраните его на компьютере.

2. **Внесите изменения в код** (`botALLPL.py`).

3. **Подготовьте файлы к отправке:**
   * Положите скачанный `bot_users.db` в папку с проектом.
   * Убедитесь, что `bot_users.db` **НЕ** указан в файле `.gitignore`.

4. **Загрузите на сервер:**
   ```bash
   git add .
   git commit -m "Обновление кода и сохранение базы данных"
   git push
   ```

5. **Перезапустите сервис** на вашем хостинге. Бот подхватит старую базу и продолжит работу с накопленной историей.

## 🛠️ Решение частых проблем

| Проблема | Решение |
|---|---|
| **Бот не отвечает / Ошибка 409** | Запущено несколько копий бота с одним токеном (например, локально и на сервере). Остановите все лишние процессы. На хостинге сделайте полный Restart сервиса. |
| **Сирена не срабатывает** | Убедитесь, что после установки фильтра вы нажали кнопку **"🔔 Включить сирену"** в главном меню. Бот также напоминает об этом при установке фильтра. |
| **Мониторинг внезапно остановился** | Благодаря новой системе защиты, при множественных сбоях сети бот безопасно останавливает поток и присылает уведомление. Просто отправьте `/start` заново. |
| **База не сохраняется** | Проверьте `.gitignore`. Файл `bot_users.db` должен отслеживаться системой контроля версий (используйте `git add -f bot_users.db`, если он был добавлен в игнор ранее). |
| **Неточные расчёты** | Увеличьте период усреднения в админ-панели. Подождите 24-48 часов для накопления достаточной истории фоновым сборщиком. |

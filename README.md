# Очередь на границе (PL) — Telegram-бот

Мониторинг электронной очереди зон ожидания на границе Беларуси с Польшей:

- **Брест** (`brest-bts`)
- **Берестовица**
- **Брузги**

Данные берутся с API [belarusborder.by](https://belarusborder.by) (как на [mon.declarant.by](https://mon.declarant.by/#/zone)).

## Возможности

- выбор погранперехода;
- периодические отчёты (интервал 3 / 10 мин или свой);
- фильтр по гос.номеру и поиск машины в очереди;
- сирена при вызове машины в ПП;
- админ-команды (список пользователей, блокировка).

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env` и укажите токен:

```env
API_TOKEN=123456:AAHxxxxxxxx
QUERY_TOKEN=test
```

Опционально те же поля можно задать в `bot_config.json`.

3. При необходимости измените `ADMIN_CHAT_ID` в `botALLPL.py` на свой Telegram `chat_id`.

## Запуск

```bash
python botALLPL.py
```

Бот поднимает Flask на порту `10000` (для keep-alive на хостинге) и polling Telegram в фоне.

## Использование в Telegram

1. `/start` или **🚀 Старт** — запуск мониторинга  
2. **🌍 Зона** — Брест / Берестовица / Брузги  
3. Выберите интервал опроса  
4. **🚗 Фильтр машины** — отслеживание номера  
5. **🛑 Стоп** — остановка  

## Структура

| Файл | Назначение |
|------|------------|
| `botALLPL.py` | основной код бота |
| `.env` | токены (не коммитить) |
| `bot_config.json` | запасная конфигурация |
| `bot_users.db` | SQLite с пользователями |
| `requirements.txt` | зависимости Python |
